# Inside OS

Jogo de plataforma 2D educativo sobre escalonamento de processos em Sistemas Operacionais: FIFO, Prioridade e Round Robin.

Desenvolvido em junho de 2025 na Godot 4.4.1. Atualizado para a Godot 4.7.

## Controles

| Ação | Tecla |
|---|---|
| Andar | ← → |
| Pular | Espaço |
| Interagir | L |
| Avançar diálogo | O |
| Pausar | Esc |

## Como jogar

Abra o `project.godot` na Godot 4.7 e aperte **F5**.
